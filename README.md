# Kambaz — Learning Management System (Backend)

A RESTful API server built with Node.js and Express.js, backed by MongoDB Atlas. Powers the Kambaz course management platform frontend.

## Features

- RESTful API endpoints for courses, users, and assignments
- MongoDB Atlas database integration
- Express.js routing and middleware
- Deployed on remote server

## Tech Stack

Node.js · Express.js · MongoDB · Mongoose

## Getting Started

```bash
npm install
npm start
```

## API Endpoints

- `GET /api/courses` — fetch all courses
- `GET /api/users` — fetch all users
- `POST /api/courses` — create a course
- `PUT /api/courses/:id` — update a course
- `DELETE /api/courses/:id` — delete a course
